# ShoreOS v2.0

个人数据管理平台 — 一套代码运行微信小程序 + H5 + React Native App。

## 快速开始

```bash
npm install
npm run dev:weapp   # 微信小程序开发
npm run dev:h5      # H5 开发
npm run build:weapp # 微信小程序构建
```

## 模块

- **fire** — 人生自由度仪表盘 (FIRE)
- **body** — 体重与身体维度管理
